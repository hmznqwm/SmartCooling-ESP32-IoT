# Folder Aset Logo Aplikasi

Folder ini digunakan untuk menyimpan gambar logo dan ikon aplikasi Smart Cooling ESP32.

### Rekomendasi Format & Ukuran:

- **Nama File:** `logoRemote.png`
- **Format:** PNG dengan background transparan atau latar putih bersih
- **Ukuran Rekomendasi:** 512 x 512 piksel (atau 1024 x 1024 piksel untuk launcher icon)
- **Path di Flutter:** `assets/logo/logoRemote.png`

Folder ini sudah otomatis didaftarkan pada `pubspec.yaml`.
